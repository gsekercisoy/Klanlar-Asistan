# Klanlar-Asistan

**"Klanlar" browser strateji oyunu için otomatik görev asistanı (erken aşama)**

</div>

> ⚠️ Bu repo şu an boş — proje planlama aşamasında. Ne yapılacağı aşağıda özetlenmiştir.

## Hedef

Tarayıcıda oynanan Klanlar strateji oyunundaki tekrarlayan görevleri (kaynak toplama,
bina yükseltme, asker eğitimi gibi rutin işler) otomatikleştiren bir asistan.

## Planlanan yaklaşım

- Tarayıcı otomasyonu ile oyun sayfasındaki görev döngüleri
- Zamanlanmış rutinler + durum takibi
- Hesap güvenliğini riske atmayan, insan benzeri aralıklar
